# APZEM Mist Collector

Static website for APZEM's industrial mist collection offering.

## Preview locally

Open `index.html` in a browser. The page uses a CSS illustration and the APZEM logo in `assets/`.

## Domain

The intended custom domain is `mistcollector.in`. GitHub Pages and DNS must be configured for the domain before it will serve this site publicly.
